# Portfolio design system — Piedra y Salvia

The portfolio uses one visual identity in two light conditions rather than two unrelated themes.

## Light — Piedra y Salvia

| Role | Value |
|---|---|
| Background | `#F2F3F0` |
| Secondary background | `#E7EBE6` |
| Surface | `#FFFFFF` |
| Soft surface | `#EEF1ED` |
| Primary text | `#111827` |
| Secondary text | `#656B66` |
| Sage | `#4C7A66` |
| Strong sage | `#2F5E4A` |
| Clay | `#C47E63` |
| Border | `#D8DDD8` |

## Dark — Carbón y Salvia

|---|---|
| Background | `#0E1411` |

| Border | `#2A3730` |
| Active border | `#638C75` |

## Meaning

- **Sage**: selection, progression, trusted states, technical structure.
- **Clay**: primary actions, important emphasis and numbered milestones.
- **Mineral gold**: secondary emphasis for automation/delivery contexts.
- **Surfaces**: depth is created with related tones instead of hard white/black contrast.
